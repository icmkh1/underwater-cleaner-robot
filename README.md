# 智能水下清洁机器人控制系统 V1.0（上位机 · 监控大屏版）

面向**水下清洁机器人（ROV）远程操控与监控**的 PySide2 上位机软件。上位机只与**树莓派 91 主控节点**建立连接，通过同一 TCP 通道同时完成：

- **视频**：接收主控摄像头 JPEG 帧（`4 字节大端长度 + JPEG`），实时显示；
- **指令**：下发 7 字段 ASCII 控制指令（推进器/舵机/刷子/灯光）；
- **监测**：连接、帧率、指令数、运行时长与各功能面板状态。

> 控制严格对齐软著《智能水下清洁机器人控制系统》：单主控连接、7 字段指令、参数限幅。

---

## 一、系统架构

```
        ┌───────────────┐   TCP 192.168.1.91:12345（指令 + 视频 + 状态）
        │  上位机(本软件) │───────────────────────────────────────────────┐
        │  PySide2 大屏  │   TCP 192.168.1.91:12346（CAM2 第二路视频，仅收流）│
        └───────────────┘───────────────────────────────────────────────┤
                                                                        ▼
                                                          ┌───────────────────────┐
                                                          │ 树莓派 91 主控节点      │
                                                          │ · 摄像头(JPEG 帧流)     │
                                                          │ · 推进器/舵机/刷子/灯光 │
                                                          │ · 灯光从控(转发)        │
                                                          └───────────────────────┘
```

| 通道 | 地址 | 说明 |
|---|---|---|
| 主通道 CAM1 + 指令 | `192.168.1.91:12345` | 视频帧流 + 7 字段指令（双向） |
| 第二路 CAM2 | `192.168.1.91:12346` | 第二路摄像头视频，**仅收流**（可隐藏） |

> 启动后**自动连接主控**；也可在左侧「主控连接」修改地址/端口后手动连接。

## 四、指令协议（7 字段，与软著一致）

```
MODE ANGLE d1,d2 s1,s2 BRUSH_STATE BRUSH_SPEED LIGHT
例：10 90 1,-1 180,180 10100 60 80
    00 90 0,0 0,0 00000 0 0      （停止/待机）
    0000                          （断开连接）
```

| 字段 | 含义 | 范围 |
|---|---|---|
| `MODE` | `10`=启动运行（采集+执行）/ `00`=停止待机 | 10 / 00 |
| `ANGLE` | 舵机角度 | 0~180 |
| `d1,d2` | 左右推进器方向（正转/反转/停止） | -1 / 0 / 1 |
| `s1,s2` | 左右推进器 PWM | 0~255 |
| `BRUSH_STATE` | **5 位** 01 字符串：小刷×4 + 大刷×1 | 00000~11111 |
| `BRUSH_SPEED` | 刷子转速百分比 | 0~100 |
| `LIGHT` | 灯光亮度百分比 | 0~100 |

- 参数在 `robot_protocol.py` 统一**限幅**；非法字符按 0；**急停** `00 90 0,0 0,0 00000 0 0`。
- 6 字段固件兼容：`robot_protocol.cmd_to_9_12_style()` 裁掉灯字段。

> ⚠️ 刷子字段已由 3 位扩为 **5 位（4 小刷 + 1 大刷）**，真机固件需同步按 5 位解析。

## 五、功能一览（共 10 个页面）

| # | 页面 | 主要功能 |
|---|---|---|
| 0 | 首页概览 | 顶部紧凑状态条；**CAM1/CAM2 等大并排**；设备状态（左图右文）；运动控制（方向 + 推进器级数/电机组合 + 多灯/刷子）；任务信息；传感器数据；推进器输出（**正转/反转/停止** + PWM）；**磁轮控制** |
| 1 | 实时监控 | CAM1 左 / CAM2 右双画面 + OSD（深度/航向/俯仰/横滚/水温） |
| 2 | 任务规划 | 顶部**仿真界面**（北区湖/仿真2 地图）；深色**航点列表**（可编辑）；**路径预览**（轨迹图） |
| 3 | 自主控制 | 参数与控制（模式/深度/航向/速度/推力上限 + 运行状态 + 暂停/急停）；摄像头；**运动控制**；**磁轮控制**；机器数据 |
| 4 | 系统设置 | 主控连接（IP/端口/自动重连）；推进器安装；视频与数据（CAM1/CAM2 各自 端口/帧率/画质）；**配置导出/导入**；系统信息 |
| 5 | 数据管理 | **指令/遥测页签分表**（遥测 **11 字段**）；记录开关；**搜索**；**清空**；**导出双 CSV（UTF-8 BOM）**；运行统计 |
| 6 | 日志信息 | 分级（正常/告警/严重）筛选；导出日志 |
| 7 | 声纳探测 | 探测设置（量程/增益/频率/开关）；目标状态/数量；回波图；目标列表 |
| 8 | 历史曲线 | 电压/电量/舱温/湿度实时趋势（大图 + 图例） |
| 9 | 系统自检 | 一键运行协议单测 + 91 节点收发回路自检，显示 PASS/FAIL |

**其他能力**：双摄像头（CAM2 可隐藏）、推进器级数/电机组合、多灯控制（灯1/2/3 + 亮度）、刷子五路（小刷1~4 + 大刷）+ 刷速、磁轮控制（自主/手动）、报警系统（阈值告警）、键盘操控（`WASD`/方向键/空格）、配置持久化与导入导出。

## 九、联调

**无真机（本地模拟）**：双击 `启动模拟91服务器.bat`（监听 `127.0.0.1:12345`）；如需第二路，再执行 `python mock_pi91_server.py --port 12346`；启动上位机后「主控连接」填 `127.0.0.1:12345`。

**真机（树莓派 91）**：同网段（电脑建议固定 IP 如 `192.168.1.99`，掩码 `255.255.255.0`）；树莓派运行 `p91_cam_server.py`（监听 `0.0.0.0:12345`）；上位机填 `192.168.1.91:12345` 连接即显示真机画面；另有第二路流时监听 `12346` 即可在 CAM2 显示。

## 十、协作与版本

- **入口唯一**：正式运行以 `main.py → dashboard.py`（单页大屏版）为准。
- **协议是契约**：改通信格式须同步 `robot_protocol.py`、`mock_pi91_server.py` 与本文档，并跑 `python self_check.py`。
- **配置**：`.venv`、`logs/`、`data/`、`config.json` 已 git 忽略；复制 `config.example.json` 为 `config.json` 后按机器修改。
- **流程**：各人在独立分支开发，`git pull` 后再改，合回主分支走合并/评审。
